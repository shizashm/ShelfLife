
# ShelfLife

## Project Overview

ShelfLife is a web application that allows readers to discover books, organize their personal bookshelves, and track their reading progress. Users can search for books, manage their reading lists, set reading goals, and receive personalized book recommendations based on their reading preferences.

## Features

- Search for books by title, author, or subject.
- View book details, including descriptions, subjects, and edition information.
- Add, move, and remove books from three shelves: Want to Read, Reading, and Finished.
- View reading statistics and track progress toward a reading goal.
- Set reading preferences and receive personalized book recommendations.
- Save books and reading preferences using localStorage, so they remain available after refreshing the page.
- Responsive layouts for desktop, tablet, and mobile devices.

## Technologies Used

- React
- Vite
- JavaScript
- HTML and CSS
- React Router
- React Context API
- Open Library API
- Browser localStorage

## Prerequisites

Before running the application, make sure you have:

- Node.js 22.12 or later
- npm (included with Node.js)
- Git (to clone the repository)
- A web browser
- An active internet connection to retrieve book data

No API key or environment variables are required to run ShelfLife.

## Installation and Setup

1. Clone the GitHub repository:

   ```bash
   git clone https://github.com/shizashm/ShelfLife.git
   ```

2. Navigate to the project folder:

   ```bash
   cd ShelfLife
   ```

3. Install the required dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in the terminal, usually `http://localhost:5173/`, in your browser.

To stop the development server, press `Ctrl + C` in the terminal.

## Testing and Production Build

The following commands are optional and can be used to check the application.

To check for linting errors:

```bash
npm run lint
```

To create a production build:

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```
